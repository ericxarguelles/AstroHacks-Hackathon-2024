# AstroHacks-Hackathon-2024

<img width="1280" height="720" alt="AstroHacks2024" src="https://github.com/user-attachments/assets/bc489419-2820-47b0-8a54-444266f12678" />

This project was built for the AstroHacks hackathon in 2024 and won 1st place 🏆. It’s an interactive space exploration app that lets users search for planets, plot routes between them, and read AI-generated planet descriptions. It was built with Unity 2021.3.36f1 and used ChatGPT’s GPT-3.5 Turbo model (`gpt-3.5-turbo`).
